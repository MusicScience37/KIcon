# How To

## ファイル

| ファイル名                | 説明                                                   |
| :------------------------ | :----------------------------------------------------- |
| KIcon_origin.JPG          | 手書きの元画像                                         |
| KIcon.svg                 | アイコンの作業用ファイル                               |
| KIcon-dark.svg            | ダークモード用アイコンの作業用ファイル                 |
| KLogo-vertical-base.svg   | タイトルをパスにする前の縦に並べたロゴの作業用ファイル |
| KLogo-vertical.svg        | 縦に並べたロゴの作業用ファイル                         |
| KLogo-vertical-dark.svg   | ダークモード用の縦に並べたロゴの作業用ファイル         |
| KLogo-horizontal-base.svg | タイトルをパスにする前の横に並べたロゴの作業用ファイル |
| KLogo-horizontal.svg      | 横に並べたロゴの作業用ファイル                         |

## アイコンの作り方

1 ～ 4 までは各種ファイルについて実施する。

1. `src/KIcon.svg` を編集
2. 背景に元画像を表示しない設定にして保存したファイルを `outputs/KIcon.svg` に配置
   - 最適化 SVG にしておく。
3. 1024 × 1024 のサイズで保存した背景透明な PNG ファイルを `outputs/KIcon.png` に配置
   - 背景が透明になるように RGBA で保存する。
4. PDF 形式で保存したファイルを `outputs/KIcon.pdf` に配置
5. `./tool.py convert` コマンドを実行

## アイコンの使い方

outputs ディレクトリの中身が https://kicon.musicscience37.com で公開されているため、
その URL を指定する。
